# Архитектура этапа предобработки

## 1. Модульная структура (новые файлы)

```
src/
├── preprocessing/
│   ├── __init__.py
│   ├── scene_detector.py        # Разбивка на сцены (PySceneDetect / FFmpeg)
│   ├── quality_analyzer.py      # Технические метрики: резкость, яркость, тряска
│   ├── content_analyzer.py      # Семантика: лица, объекты, типы сцен (опц.)
│   ├── clip_scorer.py           # Агрегация оценок в единый quality/style score
│   ├── duplicate_detector.py    # Поиск почти одинаковых фрагментов
│   ├── clip_library.py          # CRUD-обёртка для FragmentLibrary
│   └── preview_generator.py     # Генерация thumbnail и короткого превью
├── storage/
│   ├── analysis_db.py           # SQLite-обёртка (один .db файл на проект)
│   └── schema.sql               # Схема таблиц (для документации и миграций)
```

Всё хранится в скрытой папке внутри проекта:

```
{project_dir}/
└── .videoeditor/
    ├── analysis.db
    └── previews/
        ├── 1.jpg
        ├── 1_preview.mp4
        ├── 2.jpg
        └── ...
```

## 2. Схема хранения (SQLite)

```sql
-- Видеофайлы проекта
CREATE TABLE source_files (
    id          INTEGER PRIMARY KEY,
    path        TEXT UNIQUE NOT NULL,
    filename    TEXT NOT NULL,
    duration_s  REAL,
    fps         REAL,
    resolution  TEXT,          -- "1920x1080"
    file_hash   TEXT,          -- MD5 первых 64 KB (быстрый fingerprint)
    analyzed_at TEXT,          -- ISO datetime
    status      TEXT           -- 'pending' | 'analyzed' | 'error'
);

-- Найденные монтажные фрагменты
CREATE TABLE fragments (
    id              INTEGER PRIMARY KEY,
    source_id       INTEGER REFERENCES source_files(id),
    start_s         REAL NOT NULL,
    end_s           REAL NOT NULL,
    duration_s      REAL,

    -- Технические метрики [0..1]
    sharpness       REAL,
    brightness      REAL,
    contrast        REAL,
    motion          REAL,
    stability       REAL,
    action          REAL,
    calm            REAL,

    -- Контентные метрики (заполняются на уровне 2+)
    has_face        INTEGER,   -- 0 / 1
    has_person      INTEGER,
    has_subject     INTEGER,   -- наличие выраженного объекта в кадре
    scene_type      TEXT,      -- 'wide' | 'medium' | 'close' | 'detail'
    scene_tag       TEXT,      -- 'nature' | 'city' | 'interior' | ... (CLIP)

    -- Агрегированные стилевые оценки [0..1]
    quality_score   REAL,      -- общая оценка
    cinematic_score REAL,      -- F2 (плавный, стабильный, красивый)
    action_score    REAL,      -- F4 (движение, скорость, экшен)
    social_score    REAL,      -- F3 (люди, детали, городской стиль)
    premium_score   REAL,      -- F5 (максимальная стабильность и чёткость)
    travel_score    REAL,      -- F6 (цвет, атмосфера, природа)

    -- Crop-пригодность [0..1]
    crop_16_9       REAL,
    crop_9_16       REAL,
    crop_1_1        REAL,

    -- Пользовательские флаги
    user_approved   INTEGER,   -- NULL = auto, 1 = одобрен, 0 = отключён
    user_priority   INTEGER,   -- NULL | 1 (избранный)
    tags            TEXT,      -- JSON-список тегов

    -- Пути к превью
    thumbnail_path  TEXT,
    preview_path    TEXT       -- короткий .mp4 превью 2–3 с
);

-- Дубликаты
CREATE TABLE duplicates (
    fragment_id  INTEGER REFERENCES fragments(id),
    duplicate_id INTEGER REFERENCES fragments(id),
    similarity   REAL,
    PRIMARY KEY (fragment_id, duplicate_id)
);

-- Индексы для быстрого доступа
CREATE INDEX idx_fragments_source ON fragments(source_id);
CREATE INDEX idx_fragments_quality ON fragments(quality_score DESC);
CREATE INDEX idx_fragments_approved ON fragments(user_approved);
```

## 3. Поток данных

```
VideoFile (путь из папки проекта)
      │
      ▼
SceneDetector.split()
  → PySceneDetect ContentDetector + FFmpeg
  → List[Scene(start_s, end_s)]
      │
      ▼ (параллельно по сценам, ProcessPoolExecutor)
QualityAnalyzer.analyze(scene)
  → sharpness, brightness, stability, motion,
     black_frame_flag, overexpose_flag
      │
ContentAnalyzer.analyze(scene)          ← уровень 2+
  → has_face, has_person, scene_type,
     has_subject, crop_suitability
      │
ClipScorer.score(metrics)
  → quality_score, cinematic_score,
     action_score, social_score, ...
      │
      ▼
DuplicateDetector.filter(fragments)
  → убирает почти одинаковые сцены
      │
      ▼
FragmentLibrary.save(fragments)
  → SQLite INSERT + thumbnail generation (FFmpeg)
      │
      ▼
CandidateClipBuilder()                  ← уже существующий
  → теперь читает из БД вместо raw good_ranges
      │
      ▼
ClipSelectionStrategy                   ← уже существующий
TimelineBuilder                         ← уже существующий
```

## 4. Инвалидация кэша

Видео считается изменённым, если:
- изменился размер файла
- OR изменился MD5 первых 64 KB (быстрый расчёт, не весь файл)

При добавлении новых видео в папку: обрабатывать только файлы, которых нет в `source_files` или у которых `status = 'pending'`.

При удалении видео из папки: помечать связанные фрагменты как недоступные (не удалять из БД сразу, чтобы не ломать уже сгенерированные таймлайны).

### Сброс анализа вручную

В GUI: кнопка «Сбросить анализ» выполняет:
```python
db.execute("DELETE FROM fragments WHERE source_id IN (SELECT id FROM source_files WHERE path LIKE ?)", (project_dir + "%",))
db.execute("DELETE FROM source_files WHERE path LIKE ?", (project_dir + "%",))
# + удалить папку .videoeditor/previews/
```

## 5. Используемые библиотеки

| Задача | Библиотека | Уровень |
|---|---|---|
| Разбивка на сцены | `scenedetect` (PySceneDetect) | MVP |
| Резкость, яркость, тряска | `opencv-python` | MVP |
| Оптический поток | `cv2.calcOpticalFlowFarneback` | MVP |
| Черные кадры, брак | `FFmpeg` + `opencv` | MVP |
| Thumbnail / превью | `FFmpeg` subprocess | MVP |
| Хранение | `sqlite3` (stdlib) | MVP |
| Fingerprint видео | `hashlib` (stdlib MD5) | MVP |
| Детекция лиц | `mediapipe` | Уровень 2 |
| Saliency (объект в кадре) | `cv2.saliency` | Уровень 2 |
| Perceptual hash (дубли) | `imagehash` | Уровень 2 |
| Теги сцен | `open_clip` / `transformers` (CLIP) | Уровень 4 |
| Анализ музыки | `librosa` (уже есть) | — |
