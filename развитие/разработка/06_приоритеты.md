# Приоритеты разработки

---

## Обозначения

| Уровень | Значение |
|---|---|
| 🔴 Критический | Блокирует остальные задачи или MVP |
| 🟡 Важный | Нужен для полноценной работы MVP |
| 🟢 Нейтральный | Улучшает качество, не критичен для запуска |
| 🔵 Отложен | Уровень 2+ или дополнительная идея |

## Рекомендуемый порядок работы

```
Неделя 1–2:  TASK-001 → TASK-002 → TASK-003+004 (параллельно) → TASK-005
             → TASK-006 → TASK-007 → TASK-008 → TASK-013

Неделя 3:    TASK-009 (GUI-кнопка) + TASK-010 (страница фрагментов)
             Параллельно: адаптивные пороги + quality lint

Неделя 4–5:  Уровень 2 (MediaPipe + дубли + crop)

Далее:       CLIP-теги, A/B, история — по необходимости
```

---

## Что НЕ делать в MVP

- Не добавлять MediaPipe или CLIP до TASK-008 (замедлит итерацию)
- Не делать видео-превью пока нет thumbnails (TASK-006 приоритетнее)
- Не переписывать существующий пайплайн — только добавлять ветку с кэшем
- Не строить UI просмотра фрагментов до стабилизации TASK-008
