## Идея 1 — Режим «Один клик»

**Суть:** пользователь выбирает только папку с видео и музыку — всё остальное определяется автоматически.

**Как работает:**
1. Анализ материала (предобработка)
2. Автоматический выбор стиля на основе характера материала:
   - много движения → F4 (action) или F3 (urban)
   - стабильные красивые кадры → F2 (cinematic) или F5 (premium)
   - люди, лица → F3 (social) или F1
   - природа, путешествия → F6 (travel)
3. Автоматическое определение целевой длины (1× длина музыки)
4. Рендер без единого вопроса

**Реализация:**
```python
def auto_select_style(fragments: List[FragmentData]) -> str:
    avg_motion    = np.mean([f.motion    for f in fragments])
    avg_stability = np.mean([f.stability for f in fragments])
    face_ratio    = sum(1 for f in fragments if f.has_face) / len(fragments)
    avg_bright    = np.mean([f.brightness for f in fragments])

    if avg_motion > 0.55:
        return 'f4'
    if face_ratio > 0.40:
        return 'f3'
    if avg_stability > 0.70 and avg_bright > 0.45:
        return 'f5'
    if avg_bright > 0.55:
        return 'f6'
    return 'f2'  # default: cinematic
```

**Ценность для пользователя:** убирает все вопросы «какой стиль выбрать» и «какая длина нужна».

## Идея 2 — Объяснение выбора кадров

**Суть:** в лог рендера добавить краткое человекочитаемое объяснение каждого решения.

**Формат лога:**
```
[Intro]  clip3.mp4 @1:04  quality=0.91 stability=0.88  — выбран как вступление (стабильный, чёткий)
[Body]   clip1.mp4 @0:12  action=0.72  motion=0.68     — динамичный фрагмент (F4 стиль)
[Body]   clip5.mp4 @3:21  cinematic=0.85 calm=0.71     — cinematic hold (плавный переход)
[Outro]  clip2.mp4 @5:40  quality=0.88 has_face=true   — финальный кадр с лицом
[Skip]   clip7.mp4 @2:10  sharpness=0.03              — пропущен: размытый
[Skip]   clip9.mp4 @0:00  brightness=0.04             — пропущен: слишком тёмный
```

**Реализация:**
```python
def explain_selection(candidate: CandidateClip, role: str) -> str:
    f = candidate.features
    if role == 'intro':
        return f"выбран как вступление (stability={f.camera_stability_score:.2f})"
    if f.motion_score > 0.5:
        return f"динамичный фрагмент (motion={f.motion_score:.2f})"
    if f.camera_stability_score > 0.75:
        return f"cinematic hold (stability={f.camera_stability_score:.2f})"
    return f"quality={f.technical_quality_score:.2f}"
```

**Ценность:** пользователь понимает, почему система выбрала именно эти кадры, и может поправить через UI.

## Идея 3 — Адаптивные пороги отсева

**Суть:** если после стандартного отсева остаётся мало фрагментов — автоматически снижать пороги.

**Логика:**
```python
ADAPTIVE_LEVELS = [
    {'min_quality': 0.55, 'min_sharpness': 0.08, 'min_stability': 0.15},  # стандарт
    {'min_quality': 0.40, 'min_sharpness': 0.05, 'min_stability': 0.10},  # смягчённый
    {'min_quality': 0.25, 'min_sharpness': 0.03, 'min_stability': 0.05},  # минимальный
]

def get_candidates_adaptive(lib, project_dir, min_count=15):
    for level in ADAPTIVE_LEVELS:
        candidates = lib.get_candidates(project_dir, **level)
        if len(candidates) >= min_count:
            if level != ADAPTIVE_LEVELS[0]:
                logger.warning(f"[Adaptive] Using relaxed thresholds — only {len(candidates)} fragments")
            return candidates
    return candidates  # возвращаем что есть, даже если мало
```

**Ценность:** пользователь с плохим материалом всё равно получает ролик, а не пустой экран.

**Суть:** каждый рендер сохраняется в историю, пользователь может вернуться к предыдущей версии.

**Хранение:**

## Идея 5 — Настроение музыки → стиль монтажа

**Суть:** анализировать темп и характер музыки и автоматически предлагать подходящий стиль.

**Логика:**
```python
def suggest_style_from_music(music_path: str) -> List[str]:
    tempo, beats = librosa.beat.beat_track(y=y, sr=sr)
    energy = float(librosa.feature.rms(y=y).mean())
    spectral_centroid = float(librosa.feature.spectral_centroid(y=y, sr=sr).mean())

    if tempo > 130 and energy > 0.08:
        return ['f4', 'f3']  # быстрая, энергичная
    if tempo > 100 and energy > 0.05:
        return ['f3', 'f2']  # средний темп
    if spectral_centroid < 2000:
        return ['f5', 'f6']  # тёмная, атмосферная
    return ['f2', 'f6']     # default
```

**UI:**
```
🎵 Анализ музыки: 124 BPM, энергичная
   Рекомендуемые стили: [F4 Impact Sport] [F3 Urban Pulse]
```

**Ценность:** убирает неочевидный выбор стиля для новичка.

## Идея 6 — Quality lint перед рендером

**Суть:** предупреждать пользователя, если качество материала слишком низкое для выбранного стиля.

**Пример предупреждений:**

```
⚠️  Предупреждение: выбран стиль F5 (Premium Brand), но:
    • Только 8 из 127 фрагментов имеют stability > 0.45 (минимум для F5)
    • Средняя резкость материала: 0.31 (рекомендуется > 0.50 для F5)

    Рекомендации:
    → Переключитесь на F2 (Cinematic) — более гибкий к стабильности
    → Или: уберите съёмку с тряской из папки проекта

    [Всё равно рендерить F5]  [Переключить на F2]  [Посмотреть проблемные фрагменты]
```

**Реализация:**
```python
def check_style_compatibility(
    style_id: str,
    candidates: List[CandidateClip],
    settings: PresetSettings,
) -> List[str]:
    warnings = []
    min_stability = getattr(settings, 'min_stability_score', 0.0)
    good_count = sum(1 for c in candidates
                     if c.features.camera_stability_score >= min_stability)
    if good_count < len(candidates) * 0.15:
        warnings.append(
            f"Только {good_count}/{len(candidates)} фрагментов "
            f"соответствуют stability ≥ {min_stability:.2f} для {style_id.upper()}"
        )
    return warnings
```

**Ценность:** пользователь понимает проблему до рендера, не после.
