# UI/UX предложения

## 1. Размещение в интерфейсе

Предобработка не должна быть обязательным шагом — это убьёт быстрый путь.
Размещается как необязательный, но заметный этап при выборе источников.

### Блок при выборе папки проекта

```

│  12 видеофайлов  |  Общая длина: 47 мин                      │
│                                                               │
│  [🔍 Анализировать материалы]          [→ Пропустить анализ] │
│                                                               │
```

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  [ПРЕВЬЮ]    │  │  [ПРЕВЬЮ]    │  │  [ПРЕВЬЮ]    │

│ 6.1 с        │  │ 7.3 с        │  │ 7.0 с        │
├──────────────┤  ├──────────────┤  ├──────────────┤
│ 📷 широкий   │  │ 👤 лицо      │  │ 📷 средний   │
│ 🎯 стабильно │  │ 🎯 стабильно │  │ ⚡ движение  │
├──────────────┤  ├──────────────┤  ├──────────────┤
│ [✓][✗][ ★ ] │  │ [✓][✗][ ★ ] │  │ [✓][✗][ ★ ] │
└──────────────┘  └──────────────┘  └──────────────┘
```

**Кнопки в карточке:**
- `[✓]` — одобрить (система обязательно использует)
- `[✗]` — отключить (система не использует)
- `[★]` — избранный (приоритет при выборе)

### Теги в карточке

| Тег | Условие |
|---|---|
| 📷 широкий | scene_type = 'wide' |
| 📷 средний | scene_type = 'medium' |
| 🔍 крупный | scene_type = 'close' |
| 👤 лицо | has_face = 1 |
| 🧍 человек | has_person = 1 |
| ⚡ движение | motion_score > 0.4 |
| 🎯 стабильно | stability_score > 0.6 |
| 🌅 природа | scene_tag = 'nature' (CLIP) |
| 🏙 город | scene_tag = 'city' (CLIP) |

```
[Принять всё автоматически]   [Сбросить изменения]   [Выбрать стиль →]
```

## 3. Объяснение выбора кадров в рендере

В лог рендера добавлять краткое объяснение для ключевых решений:

```
[Intro] clip3.mp4 @1:04  quality=0.91  stability=0.88  — выбран как вступление
[Body]  clip1.mp4 @0:12  action=0.72   motion=0.68     — динамичный фрагмент
[Body]  clip5.mp4 @3:21  cinematic=0.85 calm=0.71      — cinematic hold
[Outro] clip2.mp4 @5:40  quality=0.88  has_face=true   — финальный кадр
```

## 4. Правила хорошего UX

- Анализ всегда опционален — нажатие «Пропустить» не создаёт трения
- Кэш показывает время последнего анализа — пользователь понимает, актуальны ли данные
- Страница фрагментов не перегружает: по умолчанию показывает только top-50 по качеству
- «Принять всё автоматически» доступна одним кликом — быстрый путь не пострадал
- Прогресс анализа показывает: текущий файл, % завершения, количество уже найденных фрагментов
- При добавлении новых видео в папку — автоматически предлагать «Обновить анализ»
