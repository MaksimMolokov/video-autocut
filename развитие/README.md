## Ключевые принципы

- Предобработка — **необязательный, но заметно улучшающий** этап
- Существующий пайплайн не ломается — предобработка подключается как улучшенный источник кандидатов
- Кэш анализа сохраняется в `.videoeditor/analysis.db` внутри папки проекта
- Разные стили монтажа используют одну и ту же библиотеку фрагментов, но с разными весами скоринга
